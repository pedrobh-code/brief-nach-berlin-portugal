# Carta à Assembleia web app

See the repository README for setup, privacy boundaries, official data refresh and Olaia deployment.

The active app is intentionally small: `src/components/Wizard.tsx`, `src/lib/lookup/`, `src/lib/generation/`, `src/lib/email/`, and the Portuguese App Router pages. Static official reference data lives in `data/parliament.json`. German-only features remain available in Git history, not as reachable routes.
